# ESP32 A 手机访问增补（2026-11-27）

本增补落实用户提出的手机访问要求，保留 ESP32 A、PC A 和独立 B/C 架构。当前完成的是候选源码与软件验证；没有烧录或手机实机验收。

## 第一版操作

首次分区迁移须另行获得明确批准并完成双读整片 Flash 备份。批准后部署候选固件和网页，再在 USB 管理页完成身份初始化及管理员登录。进入“网络连接 → 手机本地查看”，开启热点并查看连接信息。手机连接设备生成的 `AB-A-xxxxxx` WPA2 热点，浏览器访问 `http://192.168.8.1`，使用设备管理员密码登录。手机可查看状态、授权节点、模型目录、任务和结果，并导出可访问的结果。

热点默认关闭，最多两个 Wi-Fi 客户端；目前只有一个手机浏览器会话，新的手机登录会替换旧手机会话，不会替换 USB 会话。热点密码与登录密码独立。热点密码由设备随机生成，保存在 NVS，只有经过 USB 管理认证的 POST 操作可以显示或轮换。关闭、重新配置或轮换热点时清除手机会话。网页不将密码写入浏览器日志。离开网络页后重新进入会重新显示本次密码；刷新页面可清除浏览器内本次显示，不影响 NVS 中密码。

手机提示“无互联网”时应选择保留连接；不同手机是否同时保留蜂窝网络取决于手机系统。没有将 ESP32 配置为手机上网路由器。电脑和 ESP32 仍分别使用自身网络访问 C。

## 接口与边界

- USB：`192.168.7.1`，管理源必须为 `192.168.7.2`，沿用 NCM 代码和现有更新认证。
- 手机 AP：`192.168.8.1/24`，检查本地 socket、对端网段和 Host，并使用独立的限速登录、会话与 CSRF。
- `GET /api/v1/mobile/status`：USB 管理员会话，返回开关、SSID、URL、连接数，不返回密码。
- `POST /api/v1/mobile/config`：USB 管理认证，可指定布尔字段 `enabled`、`rotate_password`、`reveal`。
- 手机数据接口只允许已认证的 GET 以及只读 scope；登录和带 CSRF 的退出是必要例外。禁止手机 HMAC、Bearer 管理、API key 管理、注册、配对写入、任务提交/取消、固件和网页升级。USB 管理响应的异步任务不向手机开放。
- 不开放 STA 地址管理页；首版只支持手机直连 AP。蓝牙配网或专用 App 暂未实现，不能将其列为已完成。
- 禁止 IP 转发、NAT、NAPT、USB/Wi-Fi 桥接；AP DHCP 不提供路由器或 DNS。STA 分配到 USB 或 AP 子网时拒绝联网，防止网段冲突。
- USB 使用原有 MAC；Wi-Fi STA 沿用已分配的 factory SoftAP MAC，手机 AP 使用其派生的本地 MAC，避免冲突。

热点模式切换会停止并重启 Wi-Fi，可能短暂中断 ESP32 上行和手机连接；USB 接口不重启。扫描、Wi-Fi 试连、C 活动任务/传输或更新占用时拒绝变更。配置失败尝试恢复原无线与 NVS 配置，恢复失败明确报错。初次启动在无线电未开启时配置密码，避免广播默认开放热点。AP/STA 共用无线信道，STA 改变信道可能使手机重新连接。
