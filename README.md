# Battery System A

ESP32-S3 N16R8 电池数据交互终端：USB NCM 本地网页、ESP32 独立 Wi-Fi、系统 B 云端推理。

## 远程更新

- `updates/manifest.json`：更新清单；初始状态没有可用更新。
- 后续分别发布网页资源和 ESP32-S3 OTA 应用固件。
- 设备需通过 HTTPS 下载，验证签名、目标硬件、版本及文件完整性后才允许安装；固件支持失败回退，网页保留上一可用版本。
- 初次启用更新功能需要本地编译并通过 COM 烧录基础固件。当前仓库不包含可用固件，不能直接更新设备。

## 安全

不要提交 Wi-Fi 密码、访问令牌、签名私钥、含个人信息的配置或私有电池实验数据。
